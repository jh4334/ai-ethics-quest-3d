# 하루와 사라진 이름

금빛 책갈피를 든 어린 기록자가 되어 사라진 친구 하루의 이름을 찾아가는 6장 탑다운 3D 동화 모험입니다. 작은 섬을 자유롭게 돌아다니며 흔적과 문양을 찾고, 금빛 실과 거울잎으로 먹물 괴물을 물리친 뒤 서로 다른 비용을 가진 길을 고릅니다.

## 6장

1. `빈자리의 서랍`: 하루가 가리킨 곳보다 너무 멀리 비춘 등불
2. `저울나무가 기운 쪽`: 큰 숫자 뒤에 남겨진 여섯 이름
3. `이름을 삼킨 축제`: 아름다운 빛이 지나온 여러 손
4. `목소리를 입은 종이새`: 많이 날아도 처음 태어난 새는 하나
5. `손 없는 도장`: 세 번 멈출 수 있었던 자리
6. `하얀 방의 반딧불`: 하루가 자기 이야기를 다시 시작할 자리

어린이 화면에서는 교과 용어와 정답 점수를 사용하지 않습니다. 각 선택은 지킨 것과 치른 것을 함께 남기며, 마지막 공개 범위는 하루의 목소리를 중심에 둡니다.

## 실행과 검증

```bash
npm install --cache ./.npm-cache
npm test
npm run build
npm run smoke
npm run e2e
```

## 주소

- 운영 탑다운 3D 동화 모험: `/` 또는 `/index.html`
- 이전 2D 횡스크롤 보존판: `/illustrated.html`
- 이전 H-17 전투형 3D: `/reboot.html`
- 초기 3D 버전: `/legacy.html`

## 조작

- 키보드: `WASD`/방향키 이동, `J` 금빛 실, `K` 거울잎, `E` 살펴보기
- 터치: 왼쪽 방향 패드, 오른쪽 실·잎·보기 버튼
- 진행: 흔적 2개와 문양 2개를 찾아 열쇠를 만들고 기록문 너머의 먹물지기를 물리기

제한시간과 낙사는 없습니다. 작은 적은 마지막 생명 불씨를 끄지 못하고, 쓰러져도 찾은 단서와 열쇠는 그대로 남습니다. 장마다 자동 저장합니다.

## 안전·오프라인·에셋

- 계정·백엔드·분석·결제·개인정보 입력 없음
- 진행은 `ethics-quest-storybook3d-v1` 키의 v2 형식에 저장하며 기존 동화책 v1과 2D/3D 저장을 보존함
- WebGL 실패 시 설명과 2D 보존판 링크 제공
- 첫 온라인 로드 뒤 서비스워커로 오프라인 재실행 가능
- Kenney Mini Characters·Kenney/Quaternius 환경 CC0 GLTF와 프로젝트 고유 절차형 랜드마크 사용
- 전체 출처와 사용 위치: [ASSET_LICENSES.md](ASSET_LICENSES.md)
