# 사라진 학생 H-17 — 2D 이야기

밤의 부유 학교 원화 속에서 사라진 친구 하루의 기록과 AI 결정 경로를 추적하는 6장 2D 횡스크롤 액션 게임입니다. 이동·점프·SIGNAL 공격·TRACE 네 가지 조작으로 끝까지 플레이합니다.

기존 H-17 3D 캠페인은 삭제하지 않고 `/reboot.html`에 그대로 보존했습니다.

## 6장 캠페인

1. `명단에서 사라진 아이`: 하루의 개인정보 삭제 요청과 기울어진 위험 점수를 복구한다.
2. `거짓 영상의 주인`: 제작 이력, 최초 파일, 생성 흔적으로 조작 영상을 검증한다.
3. `웃음이 만든 폭풍`: 잘린 맥락과 추천 확산 경로를 끊고 회복 절차를 시작한다.
4. `두 개의 진실`: 필터버블 밖의 출처와 반대 증거를 교차 검증한다.
5. `아무도 결정하지 않는 밤`: AI 추천과 사람의 3초 승인을 분리해 책임 경로를 찾는다.
6. `마지막 증언`: 민감정보를 가린 증거로 WHITEOUT을 멈추고 설명·재검토·이의제기권을 복구한다.

결말은 `개인정보를 가린 공개 심리`와 `봉인 감사`의 서로 다른 비용을 보여 주며, 도덕 점수나 정답 낙인을 붙이지 않습니다.

## 실행

```bash
npm install --cache ./.npm-cache
npm test
npm run dev
```

배포 전 최소 검증:

```bash
npm run build
npm run smoke
npm run e2e
```

- 운영 진입점: `/index.html`에서 2D 게임을 직접 실행
- 같은 2D 직접 주소: `/illustrated.html`
- 보존된 H-17 3D 캠페인: `/reboot.html`
- 이전 3D 캠페인: `/legacy.html`
- 키보드: `A·D` 이동, `Space` 점프, `J` SIGNAL, `E` TRACE
- 터치: 왼쪽 이동, 오른쪽 점프·SIGNAL·TRACE

## 안전·오프라인·출처

- 계정·백엔드·분석·결제 없음
- 이름·소속·연락처 등 개인정보 입력 없음
- 진행은 브라우저 `localStorage`에만 저장
- 첫 온라인 로드 뒤 2D 게임 셸을 서비스워커로 오프라인 재실행 가능
- 외부 캐릭터와 애니메이션은 CC0 자산만 사용하며 [ASSET_LICENSES.md](ASSET_LICENSES.md)에 기록

2D 정본 서사는 [6장 스토리 바이블](docs/trilogy/게임-스토리-바이블.md), 구현·롤백 절차는 [릴리스 안내](docs/reboot/release.md)를 참고하세요.
