# H-17: NULL 개선 기획 v5 — 부족한 점 진단과 우선순위 로드맵

> 이 문서는 2026-07 당시의 진단 기록이다. 현재 6장 전면 개선의 정본과 수용 기준은 [H17-6장-전면개선-실행계획.md](./H17-6장-전면개선-실행계획.md)를 따른다.

작성: 2026-07-30. 기준 커밋 7594e81(GF1 게임필·GF2 1장 드레싱 배포 직후).
근거: 전 장면 실플레이 스크린샷, 코드 리뷰 3회(리부트 런타임·레거시·인프라), e2e 21종·유닛 378종 현황.

## 1. 현재 상태 한 줄 진단

시뮬레이션·저장·테스트 인프라는 상용급인데, **플레이어가 만나는 표면(2~5장 비주얼·오디오·첫 화면)과
공모전이 요구하는 교육 증빙(교사용 산출물)이 1장 수준을 따라오지 못했다.**

| 축 | 강점 | 부족 |
|---|---|---|
| 시스템 | 60Hz 고정 스텝·무작위 0·순수 상태기계, 원자적 세이브+메모리 폴백, 사망 복귀 | — |
| 1장 액션 | 검격 궤적·히트스톱·피격 펀치·온보딩 힌트(GF1) | 타격 사운드가 단음(얇음) |
| 아트 | 1장 복도 드레싱(GF2), CC0 캐릭터·헤어·역할 소품 | **2~5장은 원색 박스 그대로** |
| 콘텐츠 | 5장 라우팅·결말 3종·결정 기록 구조 완비 | 2~5장 플레이 밀도가 '프리뷰' 수준 |
| 교육 | 결과 카드(내 선택·변화·남은 질문), 무처벌 설계 | **교사용 산출물(리포트·인쇄) 부재** |
| 접점 | 일시정지·다시 시작·라디오 자막 | **타이틀/이어하기/설정 UI 부재**, 콜드부팅 |
| 인프라 | 롤백 체계·오프라인 SW·CI 게이트 | SW 캐시 범프 시 48MB 재다운로드, GLB 미압축 |

## 2. 부족한 점 상세 (근거 포함)

### A. 플레이어 경험
- **A1. 첫 접점 부재**: reboot.html은 접속 즉시 게임이 시작된다. 시작/이어하기 선택, 사운드·모션
  토글 UI, 조작 안내 카드가 없다(설정 값은 세이브에 존재하나 바꿀 방법이 없음). 교실에서 30명이
  동시에 켜는 상황을 견디려면 "준비되면 시작"하는 완충면이 필요하다.
- **A2. 2~5장 밀도**: 2장(Copycat)·3장(두 학교)·4장(승인실)·5장(방송)은 결정과 동사 검증 중심의
  짧은 장면으로, 1장(경로 전투 7분)과 낙차가 크다. 특히 2장은 전투 없이 결정 카드가 먼저 온다.
- **A3. 오디오**: 효과음이 오실레이터 단음 9종 + 3음 드론뿐. 타격의 '퍽'이 없어서 GF1 시각
  타격감 대비 청각이 비어 있다. 장별 무드 변화도 없다.

### B. 교육·공모전 (심사 직결)
- **B1. 교사용 산출물 부재**: 레거시(섬 게임)의 학습 리포트·인쇄 CSS·first-try 기록에 해당하는
  장치가 리부트에 없다. 결정 기록(evidence·exposure·trust)은 세이브에 전부 쌓이는데 **꺼내 볼 수
  없다.** 공모전 요건("학습 리포트·관문 신호는 깨지 않는다")을 운영 진입점이 충족하지 못하는 상태.
- **B2. 성취기준 연결 문서**: docs/trilogy의 2022 개정 성취기준 매핑이 섬 게임 기준이다. H-17
  5장(개인정보·확산·추천·자동화 승인·공개 책임) 기준으로 갱신 필요.

### C. 아트 정합
- **C1. 2~5장 드레싱 공백**: 실측 스크린샷 기준 두 학교(보라/청록 원색 벽)·방송실(파란 무대)이
  "그냥 도형" 단계다. 1장 문법(체커 타일·창문 달빛·킥라인)을 각 장 공간 은유에 맞춰 이식해야 한다.
- **C2. 게임필 이식**: 검격 궤적·히트스톱은 schoolNightScene 전용이라 2~5장 전투 검증 장면에는
  적용되지 않는다.

### D. 기술 부채 (급하지 않음, 기록)
- D1. SW 캐시 버전 범프 시 구 캐시 복사 없음 → 전원 48MB 재다운로드.
- D2. 캐릭터 GLB 미압축(ual1+ual2 ≈ 15.7MB) — meshopt로 절반 이하 가능.
- D3. `.omo` 증거 바이너리 git 추적 + Playwright 산출물 미ignore(실행마다 워킹트리 오염).
- D4. 구(v1) 세이브 보유 학생에게 리셋 안내가 없다(조용한 초기화).

## 3. 우선순위 로드맵 — 수직 슬라이스

마감·심사 임팩트 순. 각 슬라이스는 구현→유닛→e2e→실플레이 스크린샷→PR 머지로 완주한다.

### P0 (심사 직결 — 최우선)
- **P0-1 「조사 보고서」**: 캠페인 완주(또는 진행 중) 시 장별 결정·결과·남은 질문을 한 장으로
  묶은 인쇄 가능 보고서 화면. 세이브의 evidence/exposure/trust/patchChoice를 그대로 렌더 —
  새 기록 없음, 표현만 추가. 인쇄 CSS(보고서만 보임) + e2e 인쇄 격리 체크. *레거시 학습 리포트의
  리부트 대응물.*
- **P0-2 타이틀·설정 접점**: 시작/이어하기(저장 요약 리캡), 사운드·모션·화질 토글, 조작 카드
  1장. 콜드오픈 연출은 '시작' 이후로 이동. 구 세이브(v1) 감지 시 안내 문구(D4 해소).
- **P0-3 2~5장 드레싱 + 게임필 이식**: schoolAtmosphere 문법을 장별 은유로 확장(두 학교 =
  두 톤 대비 강조, 승인실 = 서류 컨베이어 실루엣, 방송실 = 조정실 콘솔·온에어 사인), bladeTrail·
  히트스톱을 공용 헬퍼로 빼서 전투 검증 장면에 연결. 예산 가드(드로콜 250·라이트 4) 유지.

### P1 (완성도)
- **P1-1 오디오 임팩트 패스**: 타격 = 노이즈 버스트+피치 드랍 합성(파일 0, 코드 생성 유지),
  장별 드론 코드 변주(1장 긴장 → 5장 해소). reducedSound 존중.
- **P1-2 2장 전투 확장**: Copycat 군집 웨이브(기존 encounters 카탈로그 재사용)로 1장에서 익힌
  동사를 복습시키고, 결정 카드는 전투 뒤에 배치(리듬: 행동→결정).
- **P1-3 모바일 실기 QA**: 터치 에뮬 전 장 플레이스루 + 44px 타깃 감사 + 세로/가로 레이아웃
  스크린샷 매트릭스.
- **P1-4 성취기준 문서 갱신**(B2): H-17 5장 기준 매핑표·차시 연결 초안.

### P2 (부채 상환)
- **P2-1 SW 캐시 마이그레이션**: activate에서 구 캐시 → 새 캐시 복사 후 정리(재다운로드 0).
- **P2-2 GLB meshopt 압축** + reboot-assets.json 대조 테스트(디렉터리 ↔ manifest).
- **P2-3 저장소 위생**: Playwright outputDir 스크래치 이동 + .gitignore, e2e의 증거 덮어쓰기
  분리(.omo는 수동 갱신 전용으로).

## 4. 하지 않기로 한 것

- 텍스처 파일 도입(외부 에셋 확대): 코드 생성 드레싱으로 충분히 읽히고, 오프라인 용량 부담만 커진다.
- 장 추가·스토리 확장: 5장 구조와 결말 3종은 완결적이다. 밀도(A2)를 채우는 게 먼저다.
- 레거시(섬 게임) 추가 개발: 롤백 비상구로 동결 유지. e2e만 그린으로 관리한다.

## 5. 검증 계획

- 슬라이스마다: 유닛(기존 수 감소 금지) · `build`+`smoke` · 리부트 e2e 21+ · 실플레이 스크린샷
  (가독성 3문항: 글씨 또렷한가 / 희멀겋지 않은가 / 어두운 곳이 짓눌리지 않는가).
- P0-1은 인쇄 e2e(보고서만 visible), P0-3은 저화질 예산 픽스처(드로콜·삼각형·라이트) 재확인.
- P1-3 완료 시점에 풀 매트릭스(데스크톱/터치 × 5장면) 스크린샷을 .omo에 수동 갱신 1회.
