# H-17: NULL — 삭제된 밤: 게임 바이블

이 문서는 리부트의 플레이 경험 정본이다. 롤백 기준은 `fa1ac50`이며, 기존 6장 캠페인과 문서는 프로덕션 전환 전까지 보존한다.

## 제품 정체성

- 장르: 3인칭/쿼터뷰 실시간 액션 미스터리 스릴러
- 대상: 12세 이상
- 플랫폼: 데스크톱 브라우저 우선, 터치 완주 지원, 정적 PWA
- 분량: 5장, 장당 25~35분, 전체 2~3시간
- 플레이어 판타지: 자신도 가담한 자동 결정의 흔적을 무기로 바꾸는 기록 침투자
- 로그라인: 축제 뒤 00시 17분, 모든 기록에서 하루가 사라진다. 플레이어는 감사 AI DOT와 학교의 디지털 트윈을 추적하지만 첫 승인 기록에서 자신의 학생 ID를 발견한다.

## 설계 기둥과 핵심 루프

1. 시작 20초 안에 이동 또는 DASH 입력을 받는다.
2. 정답 표시는 없고 행동의 결과가 인물과 공간에 남는다.
3. 공격과 조사는 같은 전투 안에서 이어진다.
4. 매 장의 반전은 앞서 배치한 단서로 추론 가능해야 한다.

30초 루프는 `위협 읽기 → DASH/REFLECT → SIGNAL BLADE → TRACE → PURGE 또는 SECURE → 결과 확인`이다.

- SIGNAL BLADE: 3타 콤보이며 마지막 타가 노출된 약점을 파괴한다.
- DASH: 짧은 무적 이동으로 추격과 회피를 잇는다.
- REFLECT: 타이밍 패리로 자동 명령을 발신자에게 되돌린다.
- TRACE: 분류와 원본 신호를 비교해 약점, 위조 표적, 증거를 드러낸다.
- SYNC CHAIN: 피격 없이 공격·패리·증거 확보를 이으면 3단계까지 오른다. 이동, 음악, 연출만 바꾸며 확률형 보상은 없다.

## 시각·카메라·UI

남색 달빛과 호박빛 기록 팔레트를 밤의 학교, 종이 기록, 유리 UI, 백색 소거 파편으로 재해석한다. 기본은 쿼터뷰 추종 카메라이며 추격과 보스 입장만 짧은 카메라 모디파이어를 사용한다. HUD는 체력, TRACE 대상, SYNC CHAIN, 최대 세 개의 주요 액션 상태만 전투 중심을 가리지 않게 표시한다.
