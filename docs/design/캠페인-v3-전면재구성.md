# AI 윤리 퀘스트 — 캠페인 v3 전면 재구성

## 목표

기존의 “4개 주제 본편 + 보너스 군도” 구조를 하나의 6장 캠페인으로 통합한다. 학습 주제는 늘리되,
모든 장이 “내가 AI에게 무엇을 보여 주었고, 그 결과에 어떻게 책임질 것인가”라는 한 질문으로 이어지게 한다.

## 6장 구조

| 장 | 제목 | 핵심 주제 | 플레이 경험 | 기억 공개 |
|---|---|---|---|---|
| 1 | 안개가 삼킨 이름 | 개인정보·편향 | 금고/씨앗 사당, 첫 두 조각 | 플레이어가 섬에 전에 왔었다 |
| 2 | 가짜 얼굴의 신전 | 저작권·딥페이크 | 명판/거울 사당, 코어 보스 | 노이즈가 플레이어를 “선생님”이라 부르고 도주 |
| 3 | 말이 남긴 상처 | 악플·혐오표현·발자국 | 말 화살 반사 + 삭제된 캡처 판단 | 플레이어의 웃음이 상처를 강화했다 |
| 4 | 같은 목소리의 바다 | 가짜뉴스·출처·필터버블 | 메아리 원본 찾기 + 추천 판단 | 노이즈는 사실보다 칭찬받는 답을 배웠다 |
| 5 | 멈추지 않는 밤 | 디지털 웰빙·AI 의존·생성물 표시 | 모래시계 타이밍 + 협업 표시 판단 | 플레이어가 도트에게 기억 삭제를 부탁했다 |
| 6 | 기억의 심장 | 책임·인간-AI 협업 | 네 동사 봉인 + 잔영전 + 최종 선택 | 아이=플레이어, 빛=노이즈 전모 공개 |

## 엔딩 재배치

- 2장 완료: `aiCoreCompleted=true`. 노이즈는 노바가 되지 않고 군도로 달아난다.
- 2장 보상: “네 가지 기초 약속 인증”. 다음 항로를 여는 중간 성취다.
- 6장 완료: `campaignCompleted=true`. 삭제/재교육 선택 뒤에만 노이즈가 노바가 된다.
- 6장 보상: “AI 윤리 수호자 완주증”.

## 세이브 v3

- 기존 `aiCoreCompleted`, `stages`, `novaLettersRead` 키는 호환을 위해 유지한다.
- `campaignCompleted`를 추가한다.
- v1/v2 세이브는 정규화 시 v3로 승격한다.
- 과거 1막 완료 세이브는 3장부터 이어 간다. 과거 군도 완주 세이브도 새 최종 선택을 경험할 수 있도록
  `campaignCompleted`를 자동 추정하지 않는다.

- 배경: 잉크 네이비 `#0B1020`

- 타이틀은 프로젝트 전용 생성 이미지를 사용하고, 실제 HUD 텍스트·버튼은 코드 네이티브로 유지한다.

## 구현 완료 상태

- 플레이어는 잉크 네이비 코트·앰버 스카프, 도트는 별방울 실루엣으로 다시 제작했다.
- 3장 `남겨진 발자국`: 복사본 삭제 → 확산 중단 → 사과·도움을 갯벌에서 순서대로 실행한다.
- 4장 `필터 버블의 창`: 원본·날짜와 맥락·다른 관점을 거울로 비춰 확인한다. 반복 추천은 증거로 인정하지 않는다.
- 5장 `표시 없는 화물`: 제작 기록을 읽고 사람 제작·AI 도움·AI 생성 라벨을 붙인 뒤 적하 목록을 검수한다.
- 3–5장 모두 핵심 도전과 후속 3D 퍼즐을 완료해야만 세이브의 장 완료 신호가 기록된다.
- 6장은 네 동사 봉인, 잔영전, 삭제/재교육 선택, 노이즈→노바 전환, 최종 완주증까지 하나의 흐름으로 연결했다.
- 외부 3D 팩은 도입하지 않았다. 현재의 낮은 폴리곤 툰 실루엣과 전용 퍼즐 소품을 한 재질 계열로 유지해 아트 방향과 런타임 예산을 함께 지켰다.

## 남은 실기기 검수

로컬 브라우저 접근 권한이 허용되는 환경에서 모바일·태블릿·저사양 WebGL 프로필의 실제 프레임과 터치 동선을 최종 확인한다.
