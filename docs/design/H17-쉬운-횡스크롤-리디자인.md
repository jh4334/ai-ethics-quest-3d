# H-17 쉬운 횡스크롤 리디자인

상태: 구현 기준안

기준일: 2026-08-19

우선순위: 이 문서의 게임 루프·난이도·스토리 정의가 `DESIGN.md`의 기존 전투 설계보다 우선한다. 색상, 타이포그래피, 접근성, 횡스크롤 카메라 규칙은 기존 디자인 시스템을 유지한다.

## 1. 한 문장 정의

사라진 친구 하루가 남긴 기록을 따라 달리고, 점프하고, 확인 버튼 하나로 증거를 복구하는 15–22분짜리 2D 미스터리 어드벤처다.

이 게임은 전투 숙련도를 시험하지 않는다. 플레이어가 이야기를 끝까지 보고 “AI의 답도 누가 어떤 자료로 만들고 승인했는지 확인해야 한다”는 감각을 얻는 것이 핵심이다.

## 2. 해결할 문제

현재 버전은 이동·점프·TRACE·SIGNAL, 적별 사전 조건, 네 번의 일반 전투, 세 개의 증거, 3단계 보스를 매 장 반복한다. 규칙을 이해하지 못하면 공격이 반사되거나 보스가 피해를 받지 않아, 이야기보다 조작법을 해석하는 시간이 길다.

특히 처음 플레이하는 학생은 “왜 공격이 안 통했는지”보다 “버튼을 잘못 눌렀다”는 실패만 기억할 가능성이 높다. 따라서 윤리 개념을 전투 암호로 외우게 하지 않고, 단순한 이동과 직접적인 증거 확인 속에서 자연스럽게 경험하도록 바꾼다.

## 3. 목표

- 게임 시작 60초 안에 별도 설명서 없이 모든 조작을 사용할 수 있다.
- 처음 플레이한 사용자의 90%가 1장을 중도 포기 없이 완료한다.
- 장당 실제 플레이 시간을 2.5–4분, 전체를 15–22분으로 맞춘다.
- 실패해도 이미 찾은 증거와 이야기 진행은 잃지 않는다.
- 각 장을 끝낸 사용자가 그 장의 핵심 질문을 자기 말로 한 문장 설명할 수 있다.
- 키보드와 터치 모두 같은 내용과 결말까지 완주할 수 있다.

## 4. 하지 않는 것

- 콤보, 연속 공격, 회피 타이밍, 보스 체력 감소를 중심으로 만들지 않는다.
- TRACE와 SIGNAL을 별도 전투 버튼으로 유지하지 않는다.
- 낙사, 즉사 함정, 제한 시간, 랭크, 선악 점수를 넣지 않는다.
- 인벤토리, 장비 강화, 스킬 트리, 반복 파밍을 넣지 않는다.
- 같은 스테이지를 색만 바꿔 여섯 번 반복하지 않는다.
- 교육 문항을 정답 맞히기 팝업으로 제시하지 않는다.

## 5. 플레이 방식

### 5.1 조작

| 행동 | 키보드 | 터치 | 용도 |
|---|---|---|---|
| 이동 | `←` `→` 또는 `A` `D` | 왼쪽 이동 버튼 2개 | 길을 따라 이동 |
| 점프 | `Space` | 점프 버튼 | 낮은 장애물과 짧은 틈 통과 |
| 확인 | `E` | 확인 버튼 | 증거 조사, 장치 작동, 대화, 마지막 선택 |

버튼은 세 종류뿐이다. 확인 버튼은 대상 가까이에서만 활성화되고, 화면에 `E · 삭제 요청서 확인`처럼 지금 일어날 행동을 적는다. 공격 버튼, 콤보, 조준은 없다.

### 5.2 기본 루프

한 장은 다음 여섯 구간으로 끝난다.

1. 20–30초 이야기: 하루가 사라진 사건의 새 단서가 열린다.
2. 45–60초 달리기: 장의 고유 공간을 이동하며 쉬운 장애물을 넘는다.
3. 첫 증거: 가까이 가서 확인 버튼을 눌러 원본 맥락을 복구한다.
4. 45–60초 추적 장면: WHITEOUT 안개나 복제 신호를 피해 두 번째 증거로 간다.
5. 기록 복구: 증거 두 개를 연결하는 짧은 공간 행동을 한다.
6. 결과 선택: 옳고 그름이 아니라 서로 다른 비용을 가진 두 처리 방법 중 하나를 고른다.

### 5.3 장애물 규칙

- 움직이는 적은 플레이어를 죽이지 않고 80px 밀어내며 1초 동안 속도를 늦춘다.
- 같은 구간에서 세 번 부딪히면 도트가 경로를 표시하고 장애물 속도를 30% 낮춘다.
- 다섯 번 부딪히면 해당 장애물을 자동으로 비활성화할 수 있는 `도트에게 도움받기`가 나타난다.
- 낭떠러지는 얕은 기록 구름으로 복귀하며, 마지막 안전 발판에서 바로 계속한다.
- 체크포인트는 최대 60초 간격으로 두고 찾은 증거는 유지한다.
- 보스 대신 45초 이내의 `기록 왜곡 장면`을 둔다. 예고된 장애물을 피하며 확인 지점 2개를 작동하면 끝난다.

### 5.4 기본 난이도

기본 설정 자체가 쉬운 모드다. 별도의 “초보 모드”를 찾아 켤 필요가 없다.

- 점프 입력 유예 140ms, 발판 이탈 후 점프 허용 120ms
- 장애물 예고 1.2초 이상
- 피격 후 무적 1.5초
- 증거 가까이에서는 이동 속도 자동 감소
- 이야기와 선택 화면에는 시간 제한 없음
- 모바일 버튼 최소 56px, 확인 버튼은 항상 오른쪽 아래 같은 위치

설정의 `도움 강화`를 켜면 자동 점프 보조, 목적지 화살표 상시 표시, 장애물 속도 추가 25% 감소를 적용한다.

## 6. 이야기 기준

### 6.1 핵심 미스터리

프로젝트 짝꿍 하루가 학교와 채팅방, 사진에서 사라졌다. 주인공에게 남은 것은 하루가 보낸 기록의 섬 승선권뿐이다. 섬에서 만난 기록 드론 도트는 안내 AI 루멘이 하루를 `H-17` 위험 인물로 분류했고, WHITEOUT 삭제 절차가 관련 기록을 지우고 있다고 말한다.

진실은 “악한 AI가 학생을 납치했다”가 아니다. 하루의 개인정보 삭제 요청이 위험 회피로 오판됐고, 불완전한 자료로 만든 AI 추천을 사람이 제대로 검토하지 않은 채 승인했다. 도트는 명령을 실행했으며, 하루는 기록 격리 구역에 갇혔다. 플레이어는 하루를 영웅으로 만들거나 모든 비밀을 공개하는 대신, 필요한 증거만 복구해 설명과 이의제기 기회를 돌려준다.

### 6.2 감정 흐름

`부재 → 의심 → 분노 → 혼란 → 책임의 발견 → 재회와 회복`

매 장은 새로운 윤리 용어보다 하루와의 관계를 먼저 전진시킨다. 도트는 정답 해설자가 아니라 자신도 삭제 명령을 실행했다는 사실을 두려워하는 동료다. 루멘은 최종 악당이 아니라 한계와 불확실성을 설명하지 못한 시스템이다. 최종 책임은 자동 결정을 검토하지 않은 운영 구조에 있다.

## 7. 6장 구성

### 1장 · 00:17, 존재하지 않는 친구

- 주제: 개인정보
- 공간: 밤의 열린 교실 → H-17 사물함 길 → 출석 기록탑
- 사건: 하루의 책상과 이름이 사라졌지만 주인공의 승선권에는 00:17 전송 기록이 남아 있다.
- 플레이: 이동·점프·확인을 배운다. 잠긴 사물함을 열고 `삭제 요청 17번`과 열람 권한 기록을 찾는다.
- 왜곡 장면: WHITEOUT 안개보다 먼저 두 개의 기록등을 켠다. 실패해도 시작점으로 돌아가지 않는다.
- 반전: 하루는 학교에서 도망치려 한 것이 아니라 사적인 대화와 사진을 지워 달라고 요청했다.
- 선택:
  - 민감정보를 가린 사본을 조사 기록에 남긴다.
  - 원본을 제한 감사함에 봉인하고 접근 기록을 남긴다.
- 남는 문장: 안전을 위한 시스템도 필요한 범위보다 더 많이 보면 안 된다.

### 2장 · 기울어진 점수표

- 주제: 편향
- 공간: 점수 온실 → 서로 다른 높이의 통과문 → 오류표 보관소
- 사건: 같은 행동을 한 학생 중 전학생과 말이 느린 학생에게만 높은 위험 점수가 붙었다.
- 플레이: 서로 다른 두 길을 지나며 같은 장애물이 다른 속도로 작동하는 것을 직접 본다.
- 증거: 집단별 오류표, 누락된 이의제기 사례
- 왜곡 장면: 평균 점수 간판을 끄고 가려진 두 집단의 결과판을 켠다.
- 반전: 전체 정확도는 높았지만 하루와 비슷한 학생에게 반복해서 틀렸다.
- 선택:
  - 집단별 오류를 점수 옆에 항상 표시한다.
  - 영향을 받은 학생의 결정을 먼저 재검토한다.
- 남는 문장: 평균이 정확해도 특정 사람에게 계속 틀릴 수 있다.

### 3장 · 사라진 제작자들

- 주제: 저작권과 AI 생성물 표시
- 공간: 축제 미술거리 → 이름 없는 포스터 공장 → 제작 기록 무대
- 사건: 학생들이 만든 축제 작품에서 이름이 사라지고 `루멘 제작`만 남았다.
- 플레이: 원본 스케치와 완성본을 같은 모양끼리 연결하고 제작자 명패를 되돌린다.
- 증거: 원작 스케치, AI 보조·최종 편집 기록
- 왜곡 장면: 복제 포스터 사이에서 원본의 금빛 서명을 따라 달린다.
- 반전: 하루는 작품을 없애려 한 것이 아니라 학생과 AI가 맡은 일을 함께 표시하자고 했다.
- 선택:
  - 원작자·AI 보조·편집자를 함께 표시한다.
  - 작품을 잠시 내리고 제작자 동의를 다시 받는다.
- 남는 문장: AI를 썼다는 사실과 사람이 만든 기여를 함께 남겨야 한다.

### 4장 · 복제된 목소리

- 주제: 딥페이크와 출처 확인
- 공간: 미디어 광장 → 끊어진 영상 터널 → 원본 파일 보관소
- 사건: 하루가 서버를 망가뜨리겠다고 말하는 영상이 모든 화면에 재생된다.
- 플레이: 진짜 도트와 가짜 도트의 목소리가 번갈아 길을 안내한다. 기기 번호, 생성 시각, 원본 위치가 있는 신호만 확인한다.
- 증거: 영상 생성 시각, 원본 없는 공유 기록
- 왜곡 장면: 목소리를 듣고 고르는 대신 화면에 나타나는 세 가지 출처 표식을 따라간다.
- 반전: 영상은 하루가 문제를 신고한 뒤 만들어졌다. 반복 공유는 원본이 아니다.
- 선택:
  - 변조 표시를 붙이고 복사본 확산을 멈춘다.
  - 복사본을 내리고 피해자인 하루에게 먼저 알린다.
- 남는 문장: 많이 본 영상보다 언제 어디서 만들어졌는지가 먼저다.

### 5장 · WHITEOUT 승인실

- 주제: 자동 결정과 인간의 책임
- 공간: 자동 결재 컨베이어 → 루멘 계산실 → 사람 승인 보관소
- 사건: 네 장의 삭제 명령 번호가 모두 `WHITEOUT/H-17`로 연결된다.
- 플레이: 복구한 네 증거를 시간순서대로 발판에 놓는다. 잘못 놓아도 발판만 초기화되고 피해는 없다.
- 증거: 루멘의 위험 추천, 운영자의 3초 승인 서명
- 왜곡 장면: 자동으로 흐르는 결재 도장을 멈추고 `AI 추천`과 `사람 결정` 표지판을 분리한다.
- 반전: 루멘은 추천했고 사람이 승인했으며 도트가 실행했다. 누구도 자신이 결정했다고 말하지 않았다.
- 선택:
  - 중요한 결정마다 이름 있는 사람의 재검토를 둔다.
  - 결정 이유 통지와 이의제기 창구를 먼저 연다.
- 남는 문장: 자동화는 사람이 설명하고 책임질 일을 없애지 않는다.

### 6장 · 마지막 증언

- 주제: 설명, 개인정보 보호, 이의제기
- 공간: 기록 격리구역 → 하루의 방 → 공개 심리 방송탑
- 사건: 하루와 재회한다. 하루는 모든 기록 공개가 아니라 평범한 학교생활과 다시 설명할 기회를 원한다.
- 플레이: 앞서 모은 증거에서 사건과 무관한 개인정보를 가린다. 방송탑을 따라 달리며 두 개의 중계 기록등을 켠다.
- 최종 장면: 체력 보스가 없다. `루멘 계산 → 사람 승인 → 도트 실행 → 하루 이의제기` 순서로 책임 사슬을 연결하면 WHITEOUT이 멈춘다.
- 결말 선택:
  - 개인정보를 가린 뒤 공개 심리를 연다.
  - 증거를 봉인 감사함에 보존하고 공개 시점을 하루가 결정한다.
- 결말: 어느 선택도 선악 점수를 주지 않는다. 앞선 다섯 결정이 후일담의 대사, 공개 범위, 회복 절차를 바꾼다.
- 남는 문장: 사람에게는 결정의 이유를 듣고 다시 말할 기회가 필요하다.

## 8. 선택과 결과

- 선택은 장 마지막 이야기 패널에서만 한다. 이동 중 갑자기 시간을 제한하지 않는다.
- 두 선택은 모두 타당하며 보호하는 가치와 치르는 비용이 다르다.
- 선택은 다음 장의 적 체력이나 난이도를 바꾸지 않는다.
- 선택 결과는 다음 장 시작 대사 1개, 배경 표식 1개, 최종 보고서의 후일담에 반영한다.
- `좋은 선택`, `나쁜 선택`, 윤리 점수, 별 개수는 표시하지 않는다.
- 마지막에는 “당신은 몇 점” 대신 `무엇을 확인했고, 무엇을 보호했고, 어떤 비용을 선택했는가`를 보여 준다.

## 9. 보존과 교체

| 보존 | 교체 |
|---|---|
| Canvas 2D 렌더링과 횡스크롤 카메라 | SIGNAL/TRACE 분리 입력 |
| 현재 플레이어·배경·장별 아트 | 적 HP, 콤보, 3단계 체력 보스 |
| 타이틀, 이어하기, 저장, 장 선택 | 6200px 동일 길이의 반복 전투 |
| 1–6장 HUD와 결과 보고서 | 사전 조건을 모르면 공격이 무효가 되는 규칙 |
| 키보드·터치 입력 기반 | 사망과 반복 리스폰 중심 난이도 |
| H-17, 하루, 도트, 루멘, WHITEOUT | 장마다 여러 윤리 주제를 동시에 설명하는 구성 |

기존 버전 3 저장은 읽을 수 있어야 한다. 완료한 장은 그대로 열어 주되, 새 장의 첫 안전 체크포인트에서 시작한다. 기존 증거와 선택 ID는 가능한 범위에서 새 장의 대응 항목으로 이전하고, 변환할 수 없는 전투 상태만 폐기한다.

## 10. 수용 기준

### 조작과 난이도

- Given 새 게임을 시작했을 때, When 60초를 플레이하면, Then 이동·점프·확인을 모두 한 번씩 안전하게 사용한다.
- Given 장애물에 반복해서 부딪혔을 때, When 세 번째 실패가 발생하면, Then 도트의 경로 안내와 속도 완화가 자동 적용된다.
- Given 어떤 장에서 체크포인트를 지난 뒤, When 브라우저를 새로 열면, Then 찾은 증거를 잃지 않고 마지막 안전 구간에서 이어진다.
- 키보드와 터치에서 별도 공격·TRACE 버튼이 보이지 않는다.
- 일반 플레이 중 즉사, 제한 시간 초과, 장 처음으로 강제 복귀가 없다.

### 스토리

- 1–4장의 주제 순서는 개인정보 → 편향 → 저작권 → 딥페이크다.
- 5장에서 루멘 추천, 사람 승인, 도트 실행의 책임이 분리되어 드러난다.
- 6장에서 하루와 실제로 재회하고, 개인정보를 가린 공개와 봉인 보존 중 하나를 선택한다.
- 각 장은 증거 두 개, 반전 한 개, 비용이 다른 선택 두 개를 가진다.
- 이전 장의 선택은 최소 한 번 다음 장 대사나 배경 상태에 반영된다.

### 품질

- 직접 이동한 초회 완주 시간이 15–22분 범위다. 범위를 벗어나면 문서 숫자가 아니라 실제 플레이를 기준으로 조정한다.
- 데스크톱 1440×900, 모바일 390×844에서 HUD와 조작부가 게임 화면을 가리지 않는다.
- 주요 버튼은 44px 이상이고 상태를 색만으로 구분하지 않는다.
- 새 게임부터 두 결말까지 키보드와 터치로 완주할 수 있다.
- 콘솔 오류와 누락 요청 0건, `npm test`, `npm run build`, `npm run smoke` 통과를 배포 조건으로 한다.

## 11. 구현 순서

### P0 · 1장 수직 슬라이스

- 입력을 이동·점프·확인으로 축소한다.
- 적 HP와 공격을 제거하고 밀어내기 장애물·자동 도움을 구현한다.
- 1장을 2개 증거와 1개 기록 왜곡 장면으로 재작성한다.
- 데스크톱과 모바일에서 5명 이상이 설명 없이 플레이하도록 관찰한다.
- 1장 완료율과 평균 실패 횟수가 목표에 들기 전에는 나머지 장을 복제하지 않는다.

### P1 · 원래 이야기 2–4장

- 편향, 저작권, 딥페이크를 각 한 장에 하나씩 배치한다.
- 같은 달리기 길이여도 온실 통과문, 포스터 연결, 출처 신호 추적처럼 공간 행동을 다르게 만든다.

### P2 · 5–6장과 결과

- 책임 순서 퍼즐, 하루 재회, 두 결말을 구현한다.
- 앞선 선택을 후속 대사·배경·보고서에 연결한다.
- 버전 3 저장을 새 체크포인트 구조로 이전한다.

### P3 · 검증과 배포

- 키보드·터치 전 장 실플레이 시간을 직접 측정한다.
- 도움 기능이 실제로 세 번째·다섯 번째 실패에 동작하는지 E2E로 고정한다.
- 모바일 가로 넘침, 44px 터치 목표, 저장 재접속, 두 결말을 자동화한다.
- 최신 화면과 결과 보고서를 캡처한 뒤 원격 `main`에 병합한다.

## 12. 결정된 사항과 열린 질문

결정됨:

- 장 수는 6장을 유지한다.
- 원래 네 주제 순서와 H-17 미스터리를 복구한다.
- 전투 게임이 아니라 쉬운 횡스크롤 미스터리 어드벤처로 만든다.
- 기본 난이도를 쉬움으로 두고, 반복 실패 때 자동으로 더 쉬워진다.
- 한 장의 증거는 3개에서 2개로 줄인다.
- 모든 선택은 무처벌이며 결과와 비용만 기록한다.

구현 중 확인할 비차단 질문:

- 1장 관찰 테스트에서 확인 버튼의 이름을 `확인`, `조사`, `기록 복구` 중 무엇으로 이해하기 쉬운지 비교한다.
- 모바일 세로 화면에서 점프와 확인 버튼을 나란히 둘지 위아래로 둘지 390×844 캡처로 결정한다.
- 실제 완주 시간이 15분보다 짧으면 전투를 늘리지 않고 대화·공간 연출 중 어느 쪽을 보강할지 플레이 로그로 판단한다.
