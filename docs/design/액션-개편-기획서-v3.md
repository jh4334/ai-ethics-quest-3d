## 2. 진단 — 왜 재미가 없었나 (v2까지의 한계)

스토리 v2(잊혀진 수호자)로 서사 긴장은 확보했지만, **이동하는 90%의 시간에 '플레이'가 없다.**
적이 없고, 위험이 없고, 손맛을 낼 대상이 없다. 젤다는 걷다 보면 싸운다 — 우리는 걷다 보면 대화한다.

## 3. 게임 필러 (v3)

1. **베어서 되찾는다** — 회색 안개가 낳은 '글리치'를 정화(전투)할 때마다 기억 파편 조각이 튄다.
2. **읽고 반응하면 이긴다** — 모든 적은 공격 전에 몸으로 말한다(텔레그래프). 죽음 대신 스태거·복구.
3. **전리품이 곧 교육** — 정화 피니셔마다 "이 잡음이 태어난 이유" 한 줄 로어 카드가 도감에 쌓인다.
4. **스토리는 그대로 관통** — 잊혀진 수호자 반전(내가 가르친 빛) 유지. 글리치 = 노이즈가 흘린 조각들.

## 4. 전투 스펙 (design-action-combat 준수)

### 플레이어 동사 (프레임 데이터, 초 단위)
| 동사 | 선딜 | 유효 | 후딜 | 규칙 |
|---|---|---|---|---|
| 베기(A) | 0.12 | 0.14 | 0.24 | 전방 부채꼴 판정 1회, 연속 3타(콤보 체인, 3타째 넉백) |
| 회피 스텝(더블탭/B) | 0.06 | 0.22(무적) | 0.18 | 이동 방향 대시, 쿨 0.9 |
| 가드(기존 방패) | 0.08 | 유지 | 0.2 | 유효 중 피격=반사, perfect 창(기존 perfectRange 재사용) |
| 정화 피니셔(A, 스태거 대상) | 0.2 | — | 0.5 | 스태거 적에게만. 파편 분수 + 로어 카드 |

### 적 공통 상태기계 (tune-enemy-ai)
`idle → pursue → windup(텔레그래프, 발광+음향) → attack(유효창) → recover(처벌 창) → (스태거) → 소멸/정화`
- 지각 입력: 거리·시야·플레이어 상태·쿨다운 타이머만. **의도 선택은 순수 함수** — 결정적.
- 동시 공격 커밋 상한 2(조우 규칙), 화면 밖 피해 금지, 즉시 회전 타격 금지.

### 적 아키타입 4종 = 윤리 주제의 육화 (build-threejs-enemy-systems)
| 아키타입 | 주제 | 행동 | 카운터(결정 디자인) |
|---|---|---|---|
| **주워듣개** (기본 몹) | — | 느린 추적 + 돌진(선딜 김) | 후딜 처벌, 첫 슬라이스용 |
| **스니처** | 개인정보 | 히트 시 파편 1개 훔쳐 도주 | 추격해 회수(손실 회피 도파민) |
| **에코 쌍둥이** | 딥페이크 | 가짜 분신 2체 소환 | 진짜만 피해 — 관찰(미세 차이) 또는 나침반 |
| **편식자** | 편향 | 한 색 오라 무적 | 거울로 오라 깨기 → 유효 창 |

### 정화 피니셔 = 도파민 + 교육 접점
스태거 → A → 버스트 이펙트 + 파편 분수(자석 흡수) + 콤보 카운터 + **로어 카드 1줄**
("이 글리치는 '허락 없이 퍼진 사진'이 뭉친 잡음이었다") → 도감 축적. 퀴즈 없음, 읽기 강제 없음.

## 5. 조우 디자인 (design-game-encounters)

- 침식 구역(안개 영역)을 **아레나**로 재활용: 구역당 조우 2개 + 기존 사당·관문 유지.
- 웨이브: 1웨이브 2~3체, 압력원 1종씩 추가. 클리어 시 구역 안개 1단계 걷힘(가시 보상).
- 사망 없음(무처벌 유지): 피격 누적 시 "기억 흐려짐" → 파편 일부 드랍(그 자리에서 회수 가능) + 무적 복구. 리트라이 동기만 남기고 벌점 없음.
- 결정적 시작: 모든 조우는 위치·구성·타이밍 고정. e2e 픽스처 쿼리로 직행 가능.

## 6. 진행 경제 (도파민 루프)

```
글리치 정화 → 기억 파편 조각(신규 재화) + 콤보 배수 → 도구 강화(3단계: 범위/쿨다운/파워)
   ↓                                          ↑
구역 안개 걷힘(스펙터클) ← 조우 클리어 ← 강해진 손맛으로 다음 아레나
```
- 파편 조각: `progress.glitchShards`(필드 추가만). 뽑기·랜덤 0 — 강화 비용 고정표.
- 콤보: 피격 없이 연속 정화 → 배수(x1→x2→x3 캡). 끊겨도 벌점 없음(8장 참여 원칙 유지).

## 7. 스토리 통합 — 버리지 않고 관통시킨다

잊혀진 수호자 반전은 유지(방금 완성, 탄탄함). 글리치의 정체가 반전을 강화한다:
**글리치 = 노이즈가 앓으며 흘린 기억 부스러기 = 결국 내가 잘못 가르친 것들의 조각.**
정화할수록 로어 카드가 회상 파편과 맞물리고, 코어 반전에서 "내가 베어 온 것들이 전부
내 실수의 조각이었다"는 층위가 추가된다. 속삭임·가짜 도트·침식 반격은 그대로 시너지.
