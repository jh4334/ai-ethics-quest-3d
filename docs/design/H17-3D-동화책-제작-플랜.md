# 하루와 사라진 이름: 3D 동화책 제작 플랜

상태: 2026-08-23 아카이브 — 새 구현 기준은 `H17-탑다운-동화-모험-재설계.md`
기준일: 2026-08-23
대체 대상: `docs/design/H17-쉬운-횡스크롤-리디자인.md`와 루트의 2D 액션 구현
## 1. 제품 정의

이 작품은 캐릭터를 조종해 싸우는 게임이 아니다. 책장을 넘기면 종이 모형이 일어나고, 독자가 빛나는 물건을 만져 사라진 하루의 흔적을 읽는 **6장짜리 3D 팝업 동화**다.

- 대상: 초등 5–6학년과 함께 읽는 교사·보호자
- 첫 완독 목표: 실제 측정 12–18분
- 핵심 리듬: 페이지 열기 → 3D 장면 관찰 → 단서 두 개 살펴보기 → 두 가치 중 선택 → 장면 변화
- 실패 요소: 없음. 체력, 적, 공격, 낙사, 제한시간, 점수는 사용하지 않는다.
- 윤리 표현: 어린이 화면에서는 전문 용어를 숨기고, 사건과 반복되는 상징으로만 보여 준다.

## 2. 디자인 기둥

### 펼치면 살아나는 책

모든 장면은 열린 책 두 쪽 위에 세운 작은 무대처럼 보인다. 페이지가 바뀌면 건물·나무·인물이 종이 접기처럼 320ms 안에 일어난다. 독자는 카메라를 끌어 약간 둘러볼 수 있지만 길을 잃지 않는다.

### 같은 금빛 실, 다른 사건

금빛 실은 여섯 장을 관통한다. 너무 멀리 비춘 등불, 기운 저울, 사라진 이름표, 빌린 목소리, 손 없는 도장, 하루의 열쇠를 차례로 잇는다. 앞 장의 선택은 다음 장 디오라마에 작은 소품으로 남는다.

### 정답 없는 두 선택

선택지는 선악이 아니라 `지금 널리 알리기`와 `당사자의 통제권 지키기`, `전체 경향 보기`와 `남겨진 사람부터 다시 보기`처럼 가치가 충돌해야 한다. 결과 화면은 얻은 것과 치른 비용을 한 문장씩 보여 준다.

## 3. 6장 3D 공간

| 장 | 디오라마 실루엣 | 살펴볼 단서 | 선택 뒤 변화 |
|---|---|---|---|
| 1. 빈자리의 서랍 | 열린 밤 교실, 별 모양 빈자리, 과하게 큰 유리 등불 | 접힌 쪽지, 너무 넓은 빛의 원 | 검은 리본 또는 발자국이 남는 달빛 상자 |
| 2. 저울나무가 기운 쪽 | 뿌리 위 저울문과 서로 다른 높이의 다리 | 여섯 이름, 뿌리에 막힌 편지함 | 작은 저울 여섯 개 또는 사람이 여는 옆문 |
| 3. 이름을 삼킨 축제 | 둥근 축제 광장과 반딧불 등불 숲 | 하루의 첫 그림, 손을 거친 긴 실 | 공동 명패 또는 잠시 접힌 무대막 |
| 4. 목소리를 입은 종이새 | 물 위 메아리 극장과 공중의 종이새 떼 | 첫 종이새의 시계, 둥지 없는 복제새 | 붉은 경고 리본 또는 조용한 둥지 |
| 5. 손 없는 도장 | 세 겹 회전 기어와 3초 시계탑 | 접힌 경고, 세 개의 책임 매듭 | 이름 있는 손자국 또는 열린 편지 창구 |
| 6. 하얀 방의 반딧불 | 흰 종이벽, 반딧불 그림, 긴 증거 책상 | 검은 리본, 하루가 묶는 마지막 매듭 | 공개 광장의 의자 또는 하루 목의 열쇠 |

모든 장은 `사건`, `발견`, `선택`의 세 펼침면을 가진다. 사건 면은 카메라와 내레이션, 발견 면은 두 개의 실제 3D 핫스폿, 선택 면은 인물 대사와 장면 변형으로 구성한다.

## 4. 조작과 접근성

| 행동 | 키보드 | 터치 |
|---|---|---|
| 다음·이전 펼침면 | `←`, `→`, `Enter` | 하단 56px 버튼 또는 좌우 밀기 |
| 단서 살펴보기 | `Tab` 후 `Enter` | 금빛 3D 물건 직접 누르기 |
| 장면 둘러보기 | 마우스 드래그 | 한 손가락 드래그 |
| 선택 | 방향키 후 `Enter` | 선택 카드 누르기 |

- 8초 뒤 도트가 첫 단서를 바라보고, 15초 뒤 두 단서가 모두 밝아진다.
- 색상만으로 상태를 구분하지 않고 번호·아이콘·텍스트를 함께 쓴다.
- 모션 감소 설정에서는 페이지 팝업과 카메라 이동을 즉시 완료한다.
- WebGL 실패 시 원인과 복구 방법, 2D 동화 롤백 링크를 제공한다.

## 5. 기술 구조

- `index.html`: 새 3D 동화책의 유일한 기본 진입점
- `src/storybook3d/content.js`: 6장·18펼침면 데이터와 시각 구성
- `src/storybook3d/state.js`: 페이지, 단서, 선택, 자동 저장을 다루는 순수 로직
- `src/storybook3d/dioramaScene.js`: Three.js 장면, 카메라, 레이캐스트, 장 전환
- `src/storybook3d/landmarks.js`: 장별 고유 랜드마크 메시
- `src/storybook3d/entry.js`: DOM·입력·저장·렌더 루프 조립
- `src/storybook3d/style.css`: 책 UI, 모바일, 인쇄 결과표

기존 `src/reboot/render/renderer.js`, `src/reboot/characters/factory.js`, `src/reboot/environment/loader.js`, `src/reboot/render/dispose.js`를 재사용한다. 전투 런타임이나 2D Canvas 코드는 새 진입점에서 불러오지 않는다.

## 6. 모델 선택

| 역할 | 선택 | 이유 |
|---|---|---|
| 주인공·하루 | Kenney Mini Characters GLB | 큰 머리와 작은 체형이 팝업 동화에 어울리고, 대기·상호작용 애니메이션을 포함한 CC0 원본 |
| 도트 | 종이별 절차형 저폴리 메시 | 이야기 고유 캐릭터이며 매우 작아 외부 모델보다 직접 저작이 가볍고 정확함 |
| 교실·가구 | Kenney Building/Furniture GLB | 단순 도형이 아닌 실제 모델, CC0, 팝업북 비율과 잘 맞음 |
| 숲·축제 | Quaternius Stylized Nature + Kenney Nature GLB | 수채화풍 저폴리 실루엣, CC0, 모바일 비용이 낮음 |
| 장별 상징 | 직접 저작한 곡면·압출 메시 | 저울나무·종이새·시계탑 같은 고유 장면은 범용 에셋보다 서사 전달이 우선 |

캐릭터 모델은 전투용 Ranger 단독 모델이나 공격 애니메이션을 쓰지 않는다. 기존 학생/peasant 조합을 동화 팔레트로 재질 조정하고 대기·상호작용 애니메이션만 로딩한다.

## 7. 단계와 통과 기준

### P0: 1장 완성본

- 책 표지, 페이지 팝업, 주인공·도트, 밤 교실, 빈자리, 서랍, 유리 등불 구현
- 단서 두 개와 선택 두 개, 자동 저장 구현
- 데스크톱/모바일 실제 캡처로 글·캐릭터·단서 가독성 확인

### P1: 2–6장 확장

- 장마다 다른 카메라·지형 높이·랜드마크·상호작용 구현
- 앞 장 선택의 소품 흔적을 다음 장에 반영
- 6장 마지막 선택 뒤 하루 이름이 교실 명단으로 돌아오는 엔딩 구현

### P2: 제품 마감

- 새 게임/이어 읽기/목차/모션·화질 설정/조작 안내
- 인쇄 가능한 독서 기록: 본 단서, 고른 행동, 지킨 가치, 치른 비용
- 서비스워커 캐시 갱신, 장별 지연 로딩, 모바일 저화질

### 최종 검증

- `npm test`, `npm run build`, `npm run smoke`, 전용 E2E 통과
- 6장 새 게임부터 결말까지 키보드·터치 완독
- 새로고침 이어 읽기, 장 재방문, WebGL 실패 안내 정상
- 데스크톱 1440×900, 모바일 390×844 최신 캡처
- 콘솔 오류·HTTP 실패·누락 에셋 0건
- 루트에는 Three.js 3D만 로드하고 2D 액션 코드를 로드하지 않음
- 롤백 경로 세 개와 기존 저장 키를 보존
