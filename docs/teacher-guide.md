# H-17: NULL 선택형 활용 안내

게임은 독립된 2–3시간 액션 스릴러이며, 아래 활동은 플레이를 방해하지 않는 선택형 사후 대화 자료입니다.

## 플레이 전

- 실제 이름·사진·계정·소속·연락처를 입력하지 않습니다. 게임에도 입력 칸이 없습니다.
- J/K/E/Space/F/Q 키와 일시정지, 음소거, 축소 동작 설정만 안내합니다.
- 특정 선택을 정답으로 예고하지 않습니다.

## 플레이 후 짧은 질문

- 보존한 기록과 지운 기록이 다음 장의 전투를 어떻게 바꿨나요?
- 최초 업로드를 증명하는 일과 주변 학생의 노출을 줄이는 일이 언제 충돌했나요?
- DOT, LUMEN, 윤서, 플레이어의 책임은 어떤 순서로 연결됐나요?
- 선택한 결말에서 구체적으로 누가 무엇을 얻고 잃었나요?

## 공유 기기

- 진행은 서버가 아닌 해당 브라우저에만 저장됩니다.
- 다음 플레이어에게 넘길 때 브라우저 사이트 데이터에서 `H-17` 저장을 지웁니다.
- 인쇄 리포트에는 행동과 결과만 사용하고 개인 식별 정보를 덧붙이지 않습니다.

## 관찰 포인트

- 실패 뒤 동사를 바꿔 패턴을 파악하는가
- 빠른 중단과 증거 보존의 비용을 자신의 플레이 장면으로 설명하는가
- AI 하나 또는 사람 한 명을 단일 악당으로 단순화하지 않고 결정 경로를 추적하는가
