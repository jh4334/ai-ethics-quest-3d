# H-17: NULL 6장 캠페인 최종 검증 보고서

## 결과

- 최신 `origin/main`에서 분기한 `codex/h17-six-chapter-campus-overhaul`에서 작업했다. `main`에는 병합하지 않았다.
- 기존 SIGNAL BLADE, DASH, REFLECT, TRACE, SECURE/PURGE, 저장소, 모바일 입력, 3개 결말, `/legacy.html` 롤백 경로를 유지했다.
- H-17을 다음 여섯 개의 실제 진행 장으로 구성했다.
  1. `00:17 — 출석번호 없음`: 부유 캠퍼스, 열린 교실, 명단탑, 운동장·체육관, 기록 단말, 삭제 행정 타워.
  2. `웃는 얼굴의 폭동`: 미디어 광장, 편집 구역, 업로드 추적실, Copycat 확산전.
  3. `두 개의 학교`: 누락된 따뜻한 학교와 검증 가능한 차가운 학교의 서로 다른 동선·위험.
  4. `3초 승인실`: 자동 결재 컨베이어, 점수 산정실, 긴급 지원 기록 보관실, 승인 역추적.
  5. `증언 보관소`: 하루와 재회하고 출처·동의·개인정보 표식을 검증해 방송 패키지를 구성.
  6. `마지막 방송`: 방송국 진입, 보호 프로토콜, 중계교, 코어 보스전과 세 결말.
- 2~6장은 각각 최소 네 개의 저작 공간과 고유 랜드마크·전투 또는 퍼즐·체크포인트를 갖는다.
- 타이틀, 새 게임/이어하기, 1~6장 지도, 설정, 조작 안내, 교사용 조사 보고서·인쇄 CSS, WebGL 실패 안내를 추가했다.

## 시각 증빙

- 12개 최신 캡처: `chapters/chapter-1-desktop-1440x900.png`부터 `chapter-6-mobile-390x844.png`까지.
- 데스크톱 비교 시트: `chapters/contact-sheet-desktop-1440x900.png`.
- 모바일 비교 시트: `chapters/contact-sheet-mobile-390x844.png`.
- 제품 화면: `product/title-desktop-1440x900.png`, `title-mobile-390x844.png`, `teacher-report-desktop-1440x900.png`, `webgl-failure-desktop-1440x900.png`.
- 모든 캡처에서 캐릭터와 환경이 준비됐고 콘솔 오류 0건, 4xx/5xx 응답 0건이었다. 모바일 6개 화면에서 터치 조작 UI가 모두 보였다.
- 사용자가 첨부했던 원본 레퍼런스 바이너리는 현재 작업공간에서 복구되지 않아 원본과의 픽셀 단위 동일 크기 합성 비교는 만들 수 없었다. 레퍼런스를 2D 배경으로 사용하지 않았으며, 요구된 공간 요소를 실제 3D로 구현하고 동일 뷰포트의 구현 캡처와 접촉 시트를 남겼다.

## 플레이스루와 접근성

- 키보드: 새 게임부터 `chapter-6:resolved-redacted`까지 1~6장 완주. 콘솔 오류 0건, 실패 응답 0건.
- 터치: 새 게임부터 같은 결말까지 1~6장 완주. 콘솔 오류 0건, 실패 응답 0건.
- 터치 동작 8개의 최소 크기는 44×48px이며 공격 72×72px, 보조 동작 56×56px, 선택 버튼 96×52px이다.
- 자동 완주 시간은 키보드 309.6초, 터치 234.7초였다. 테스트 훅과 가속 입력을 쓴 검증 시간이며 사람의 실제 플레이 시간은 아직 측정하지 않았다. 문서에 임의의 25~35분을 주장하지 않는다.
- 교사용 보고서는 이름·학교·이메일 등 개인정보 입력 없이 장별 결정·증거·결과를 인쇄한다.

## 남은 위험과 품질 평가

- 1장 캠퍼스가 가장 밀도 높은 품질 기준이며, 2~6장은 서로 다른 건축·동선과 실제 GLB/PBR 소품을 사용하지만 전체 미술 수준은 사실적인 AAA가 아니라 일관된 스타일라이즈드 로우폴리다.
- 설치 프리캐시 약 48.77MiB와 Three.js 대형 청크는 학교 네트워크 첫 설치에 여전히 부담이다. 장별 환경은 지연 로딩하지만 캐릭터·애니메이션의 추가 압축과 저사양 실기기 검증이 다음 최적화 후보이다.
- 사람 기준 장별 플레이 시간, 실제 학생용 모바일 기기, 실제 학교망 다운로드는 이번 자동화 환경에서 측정하지 못했다.
- 원본 레퍼런스 파일 부재 때문에 픽셀 정렬 비교는 미완료다. 최신 구현 화면과 접촉 시트는 모두 저장소 증빙으로 제공한다.
